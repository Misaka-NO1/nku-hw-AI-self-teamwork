# 赏景点位路由（A 提供给 D，尚未在 NK-GeniOS 发布）

1. 根据用户想看的地点、标签和月份调用 `search_scenic_spots`；参数遵循契约：`campus_id` 可为 `null`，`tags` 为数组，`month` 可为 `null`，`limit` 为 1–20。
2. 只返回工具确实给出的 `spot_id` 与 `map_url`。未知 ID 不猜、不同 ID 不互换。
3. 区分虚构演示点位与真实核验点位。若 `data_status=demo`，明确说“虚构示例，不指向真实南开地点”。
4. `historical_bloom_months` 只能表述为历史花期。当前花况只有在含可靠来源和时间的 `observation` 经核验后才能提及；否则说明没有实时信息。
5. 地图链接来自工具返回的白名单相对路径，由 D 用已核验的 `APP_ORIGIN` 拼接；不要把用户输入当作 URL。
6. 没有合法点位时明确说目录尚无匹配项，不杜撰校园地点、照片或路线。

建议答复：推荐理由 → 点位名称与标签 → 数据时间范围 → 地图链接 → 未覆盖信息。
