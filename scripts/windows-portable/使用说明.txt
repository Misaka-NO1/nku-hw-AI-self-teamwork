南开大学津南校区地图 · Windows 免安装预览版

1. 将整个 ZIP 解压到一个文件夹；不要在压缩包预览窗口内直接运行。
   如 Windows 仍提示“路径太长”，请把 ZIP 放在 C:\NKU 再解压，不要逐个跳过文件。
2. 双击“启动地图.cmd”，默认浏览器会自动打开地图。
3. 地图和图片均在本机读取，无需安装 Node.js，也无需联网。
4. 请保持启动窗口打开；关闭窗口即停止地图。如果浏览器没有自动打开，复制窗口中的 http://127.0.0.1:端口/ 地址手动打开。

这是只读预览版：可旋转、缩放、搜索景点、浏览照片和简介；不提供编辑功能。服务只监听本机 127.0.0.1。
浏览器页面不是离线 HTML 文件，请通过启动地图.cmd 打开；不要直接双击 index.html。
模型按参考图人工对位，并非测绘成果。未经处理的照片原片不在本包内。
