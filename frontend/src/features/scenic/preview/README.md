# 赏景地图独立本地预览

此入口只加载 A 的 `ScenicPage` 和虚构 demo 目录，不依赖 C 的公共前端或 D 的服务。
它是外部网页组件的预览，不是已经导入 NK-GenioS 的插件，也不提供真实校园底图、照片或实时花况。

在本目录运行：

```powershell
npm ci
npm run dev
```

按终端显示的地址打开浏览器（默认 `http://127.0.0.1:5173/`）。可检查拖动画布、滚轮/按钮缩放、标签筛选、点位点击、详情/返回、浏览器前进后退和 `?spot_id=demo-spot-01` 深链接。访问 `?spot_id=missing` 应显示明确的找不到状态。画布完整适配视窗时没有可拖动的溢出区域；先放大再拖动。

开发模式下访问 `http://127.0.0.1:5173/?mode=authoring`，点击“添加景点”，再点击地图空白处，会打开新增窗口。可填写名称、简介和标签，保存后立刻出现标记，也可编辑点位、导入/导出本地 JSON。还可临时载入不超过 20 MB 的 PNG/JPEG/WebP 底图，查看点位在不同图片上的位置；图片不会上传，也不会包含在 JSON 导出中。浏览器刷新前的数据只存在内存里，记得导出 JSON 并另存图片。不能把虚构点位当成真实南开位置。

构建检查：

```powershell
npm run build
npm run typecheck
```
