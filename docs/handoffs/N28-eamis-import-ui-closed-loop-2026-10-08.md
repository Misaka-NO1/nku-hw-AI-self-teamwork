## 实现

1. 教务登录由本人完成。扩展只在白名单课表页点击按钮后读取课程区域文本，不读取密码、Cookie、SSO 或整页 HTML。
2. 每次读取使用独立临时交接编号，打开正式工具站 `/tools/import`；扩展与 React 双向就绪握手，防止谁先加载造成数据丢失。
3. 没安装扩展时可下载课程区域 HTML 或导入 JSON/CSV；解析过程移除资源与执行节点，不把外部 HTML 挂到活动页面。
4. 学期第一周周一、教学周数、节次时间需核对；未经核实不标官方校历。校历和课程均可在核对页修改。
5. 修改任何核对内容使之前草稿确认失效。生成云端草稿与最终替换本人课表是两个明确动作；后端校验契约、周次和节次后持久保存。
6. 最终保存有确认回执、内容 hash、幂等键、版本校验。旧草稿不能覆盖新版本；读回版本不符不显示假成功。
7. `/tools/timetable` 使用原来的 `TimetablePage`，读取新版本后显示周／日 UI。没有另做一套课表，导入不写待办日历。
8. 已保存课表可重新进入核对页修正后保存新版本；通知模块经授权读取最新本人课表计算。

## 数据库迁移与部署

- 新增 `personal-schedules-migration.sql`，必须在原有 persistent-auth 迁移之后执行。只新增三张私人表并包裹现有身份 RPC，不删除或重种既有课表、待办、用户、授权。
- 只允许原有服务端 RPC 访问表；本人归属由已验证会话/授权确定，不能由模型或 URL 任意指定。
