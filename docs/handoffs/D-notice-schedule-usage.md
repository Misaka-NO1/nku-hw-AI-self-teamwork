2026-10-06更新：负责人要求只完成其他逻辑、前端由别人负责。本轮新增云身份/PG文本与单图OCR后端候选，默认关闭且尚未上线；前端不再继续开发。最新接口、字段及接入步骤见[D后端交接](D-notice-backend-interface-2026-10-06.md)。下文保留10月5日本地页面的历史操作证据。

## 支持范围

仅自编虚构文字通知及仓库演示课表。支持逐句拆分固定活动、截止任务，完整年月日及HH:MM时刻；“今天/明天/本周五”等须给明确参照日期。无年份日期也须参照。原文、字段证据和未识别段落可查看；读取字符覆盖不代表已经语义识别全部事项。

日期缺时刻、耗时未知或最早开始未知都要补充，不自动补23:59，不估算耗时。取消、变更、多日期、混合动作需更正/拆分原文。当前受限读取器并非学校大模型；地点等复杂字段尚不能完整提取。截图、PDF、链接抓取未实现。

## 启动

先安装PR中的锁定依赖。后端在`backend`目录启动：

```powershell
$env:NOTICE_TEXT_PILOT_ENABLED='true'
$env:APP_ENV='development'
$env:APP_ORIGIN='http://127.0.0.1:5173'
$env:DATABASE_URL='sqlite:///../.local-notice-pilot-data/campus.db'
New-Item -ItemType Directory -Force ../.local-notice-pilot-data | Out-Null
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另一个窗口在`frontend`目录启动：

```powershell
$env:VITE_API_BASE_URL='http://127.0.0.1:5173'
$env:VITE_NOTICE_TEXT_PILOT='true'
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

打开`http://127.0.0.1:5173/tools/tasks?notice_pilot=1`。后端开关默认关闭，且只允许本机development/test和demo_fixture；前端还要求专用查询参数。直接进入原`/tools/tasks`仍是已有固定演示页面。

## 一次完整操作

1. 点“确认使用虚构数据并开始”，创建独立浏览器会话；查看演示课表摘要，再点击确认导入。
2. 粘贴“请在2026年9月21日10:10前提交虚构实验总结，材料：总结PDF。”，点“读取并逐项核对”。这里的历史日期只是算法回归数据。
3. 核对原文；填预计20分钟、最早2026-09-21 09:40；查询2026-09-21 08:00—12:00。
4. 点“重新计算冲突或候选时间”。实际B算法返回09:40—10:00；页面同时提供本次请求/原始结果和覆盖说明。
5. 选择候选，生成草稿，最后核对后点击确认保存；重新读取待办可看到工作时间。刷新/后端重启后同一未到期会话仍可读回。
6. 改成60分钟或收窄查询时间后必须重新计算。修改字段立即隐藏旧推荐和确认；保存前也重新读取当前课表/任务检查候选是否有效。

固定活动显示具体课程/活动冲突和交集。存在冲突时必须明确勾选“仍要保存”并重新计算核对。查询范围不超过31天，活动完整起止须包含在范围内；仅反映已导入课表和已确认活动，范围外/未知安排不能视为确定有空。

## 保存与隔离

复用现有Cookie、CSRF、owner工作区、草稿revision/payload_hash、确认票据、幂等提交和SQLite。截止时刻保留为截止；只有确认选定的工作区间作为忙碌安排。未确认草稿不占时间。相同事项不能另存一条；候选期间新增忙碌冲突会阻止旧计划保存。

接口不接收caller owner/workspace或任意课表覆盖。自动化两独立浏览器会话的隔离通过，但这不等于两个真实学校账号验收。会话到期需重新开始；当前不支持重新打开未提交草稿的深链接。

## 下一阶段

学校通用模型工作流只有候选源码和提示词，尚未安装/Debug；其输出只允许待复核，不直接计算或保存。最新云身份与PG存储仍只接受固定演示数据，不能直接开启本地试点开关。需要在现有本人身份之上设计隔离云文本存储，接学校本人时间工具、受控复核与选定工作区间，再实测新通知和两个普通账号；其后增加至少一种截图输入。
