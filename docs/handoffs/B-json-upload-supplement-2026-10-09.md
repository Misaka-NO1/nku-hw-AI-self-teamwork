# B 课表模块补充：JSON 文件导入与明确结果提示

本轮属于 **给 B 的课表模块补充**，承接已合并的 PR #12 / #13，不替代或重复归属 B 的原有成果。

## 修复内容

- 原始教务 JSON 不包含校历；连接壳之前没有把本人已保存课表的校历传入文件导入页。现在同学期可沿用本人已确认校历，完整课表 JSON 也能载入其已确认校历。学期不同必须重新核对，不套用旧日期。
- 首次导入先选课程文件、再核对校历时，保留已选文件并自动继续解析，不用再次选文件。支持 UTF-8 BOM；缺少 `File.text` 的浏览器使用 `FileReader`。
- 关闭系统文件选择框会触发浏览器焦点事件及登录核验。原页面随核验卸载重建，导致文件、异步读取和预览丢失。现在核验期间保持组件和页面布局，但隐藏本人内容、禁用操作；核验为同一账号后恢复进度，换账号或登录失效时丢弃旧进度。
- 上传/保存异步链路增加会话核验代际检查，核验发生后不能继续后续写入。原有本人确认、草稿版本、幂等键和数据库读回校验不变。
- 顶部固定进度提示区分：正在读取、缺校历、文件读取成功、已上传云端草稿、保存成功；错误明确显示。正式“保存成功”只能在提交回执与本人数据库读回版本一致后显示。

- 前端 220 项回归通过，含真实会话钩子下的 `window.focus` + 延迟文件读取复现、不同账号隔离、登录失效、核验期间禁止继续提交、保存读回失败不假报成功。
- 类型检查与 identity 构建通过；公共测试只含虚构样例。真实文件的可选本地测试由 `EAMIS_PRIVATE_JSON` 指定，文件内容不进仓库。
- 创建 PR 前，从已提交代码生成隔离快照再次验证：前端 **217 项通过**、类型检查通过；解析器 **58 项通过、2 项可选私人文件测试默认跳过**。工作区全量 220 项比快照多出的 3 项是未进入本 PR 的访客登录测试，不是课表测试遗漏。
- 线上最终版本为工具站部署 037（r40），正常、100% 流量、1 个实例。包与前序已部署基线比对：103 个非前端文件及读取扩展保持不变，没有新增身份权限或修改 Agent。
- 实际选取本地教务 JSON，核对校历后解析出 10 门课程、25 条上课安排；本轮线上验证没有生成新云端草稿或重新保存课表。
- 用户另行明确确认清除其本人已有课表后，已做限定目标清除并验证空课表；日历与其他账号数据保持不变。这是已完成的线上操作记录，**不是 PR 内的自动清空代码或部署步骤**。

## 使用与边界

1. 进入工具站“导入与核对”，在第二步选择教务导出的 `timetable-import.json`。
2. 如提示缺校历，在第一步确认学期第一教学周周一与节次时间；文件会自动继续解析。
3. 核对预览，点击生成本人课表草稿，再点击明确确认保存。以顶部“保存成功”与本人数据库读回为准。

手机可选择已经导出的 JSON 文件，不要求安装扩展；尚未做实体手机验收。普通手机网页直接跨站读取已登录教务页不是本轮实现范围。浏览器固定设备码、访客免注册、赏景常驻实例等其他工作不在本 PR。

不上传真实教务文件、课程截图、录屏、设备码、Cookie、令牌、云端环境变量、构建包或数据库。
