## 课表时间规则

`native-identity-agent-live-append.txt` 保留完整身份分流，并包含 `【课表时间准确性】`。当前已使用新身份规则的草稿，在该规则附近加入这个时间段落且只保留一份；若时间段落已有旧版，整段替换。

只有仍带旧绑定锚点的历史提示词才使用 `repair_native_binding_prompt.py INPUT OUTPUT`；该脚本会保留其他非空段落、替换旧绑定规则并带入新的时间规则，锚点不唯一或超出字节上限会报错。不要将它直接应用于已修复的新草稿，也不需要把完整线上提示词提交到仓库。

验收至少检查一个跨三节课的 meeting：按查询日期筛选教学周和星期，开始使用 `start_period` 的 `start`，结束使用 `end_period` 的 `end`，两端节次都包含。缺少对应节次时间时应说明无法确定；不可截去最后一节后据此声称空闲。
