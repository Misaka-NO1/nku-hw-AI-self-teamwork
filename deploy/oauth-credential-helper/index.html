学校填原文，腾讯云填摘要

这不是登录页。仅在本机内存计算 OAuth 客户端密钥的 SHA-256 摘要，不联网、不保存文件，也不自动提交腾讯云或学校表单。

只更换现有 OAuth 客户端凭据，不改账号、空间、课表、日历或权限。不要填数据库 Key、登录密码、MCP Token 或专用身份插件 Token。关闭本页后内容丢失，请用密码管理器保管客户端密钥；不要发送到聊天。

1. 准备同一串密钥，复制到学校插件

粘贴你准备使用的 40–256 位客户端密钥，或点击生成按钮生成一枚新密钥。点击“复制客户端密钥”，粘贴到学校新插件 campus-private-space-oauth-recovery 的 client_secret 并保存。两端必须使用这一次计算的一对值；复制摘要前不要再次点击生成。

2. 摘要填写到腾讯云后端

只用于 nku-campus-identity-pilot 后端配置；不填前端、知识库或 Agent 提示词。

固定配置

client_id / OAUTH_CLIENT_ID
nku-genios-identity-read-pilot-20261003
现有 Scope（不扩大权限）
demo:read tasks:read tasks:write devices:bind degree:read degree:write

https://coze.nankai.edu.cn/product/llm/info/oauth
